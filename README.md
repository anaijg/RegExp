1. Clona este repositorio en tu equipo local. 
2. Antes de empezar: crea una rama con tu nombre
```shell
git checkout -b anaij
```
3. Trabaja en tu rama para solucionar los ejercicios
Cuando finalices, o cada cierto tiempo, por ejemplo cuando termines un ejercicio, confirma los cambios.
```shell
git status
git add .
git commit -m "commit_message"
git push origin branch_name
```
